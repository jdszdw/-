# 霓虹贪吃蛇

一个可以直接部署分享的网页版贪吃蛇小游戏。

## 本地体验

双击 `index.html`，或者用任意静态服务器打开项目目录。

## 快速分享

### 方法 1：Netlify Drop

1. 打开 <https://app.netlify.com/drop>
2. 把这个文件夹整个拖进去
3. 等待上传完成，复制 Netlify 生成的 `https://...netlify.app` 链接发给好友

### 方法 2：GitHub Pages

1. 在 GitHub 新建一个公开仓库
2. 把本目录所有文件推送到仓库的 `main` 分支
3. 在仓库 Settings -> Pages 里选择 GitHub Actions
4. 等 Actions 跑完，页面会生成 `https://你的用户名.github.io/仓库名/`

## 操作

- 方向键或 `WASD` 控制移动
- `Space` 暂停或继续
- `Enter` 开始
- 手机端可以使用页面下方方向按钮
